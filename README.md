# Responsive-Glassmorphism-Navbar

A responsive glassmorphism navigation bar built with **HTML, CSS, and JavaScript**. This project was created to understand how responsive web designs are structured and implemented across different screen sizes.

## Purpose

The main purpose of this project is to understand **how responsive design is created in frontend development**.

This project helped me practice:

- Creating responsive navigation layouts
- Using CSS media queries
- Designing for desktop, tablet, and mobile screens
- Creating a hamburger menu
- Building a responsive sidebar
- Handling navigation interactions with JavaScript
- Creating glassmorphism UI effects
- Adding CSS hover and transition effects
- Making layouts work on small mobile screens

## Features

- Responsive navigation bar
- Glassmorphism UI
- Responsive hamburger menu
- Mobile sidebar navigation
- Sidebar open/close functionality
- Escape key support for closing the sidebar
- Navigation link hover animation
- Backdrop blur effect
- Responsive layout for different screen sizes
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts (Poppins)
